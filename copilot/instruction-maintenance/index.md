# Instruction Maintenance

* [Improving Instructions After a Missed Issue](improving-instructions.instructions.md) - How to turn an issue that review missed into a validated, generic instruction

# Scope

* This bundle and other agent instruction files, rather than the code a task is
  otherwise changing.
* Authoring covers the mechanics of an instruction file; the improvement process
  covers deciding what a new instruction should say.
